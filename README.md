# Cooker Whistle Counter

Counts pressure-cooker whistles so food doesn't overcook while you're nearby.

- **Problem source**: [Reddit request (157 upvotes)](https://www.reddit.com/r/developersIndia/comments/1isvhnk/whats_your_i_wish_there_was_an_app_for_that/) — "an app to count the number of whistles a cooker has completed while cooking (especially rice)".
- **Two modes**: microphone auto-detection (band-energy whistle detection, all audio processed locally) and a manual tap counter with target alarm.
- **Run it**: open `index.html` in a browser, or use the GitHub Pages site. Mic mode needs HTTPS, mic permission, and the tab kept open with the screen on.

## Honest limits

This is a **supervised cooking aid, not a safety device**. Detection can miss whistles or false-trigger on background noise (TV, horns, mixers). Never leave a pressure cooker unattended relying on this page. No audio is recorded or uploaded.
